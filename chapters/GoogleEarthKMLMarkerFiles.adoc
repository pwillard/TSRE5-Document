= Creating KML Marker Files in Google Earth

This section explains how to create simple KML marker files in Google Earth Pro. KML files are useful for sharing route reference points, station locations, landmarks, survey notes, and other geographic markers.

== KML and KMZ

Google Earth can save placemarks and folders in two related formats:

KML::
A plain text XML file. This is the best choice when the file should be readable, editable, documented, or generated by scripts.

KMZ::
A zipped KML package. This is useful when the marker set includes bundled icons, images, overlays, or other resources.

For simple marker lists, use KML.

== Creating a Single Marker

. Open Google Earth Pro.
. Navigate to the location where the marker should be placed.
. Click the yellow pushpin button, or choose menu: Add[Placemark].
. Enter a name for the marker.
. Optionally enter a description.
. Position the marker:
.. Drag the pushpin to the exact location, or
.. Enter latitude and longitude manually in the placemark dialog.
. Click btn:[OK].
. In the Places panel, right-click the new placemark.
. Choose menu: Save Place As[].
. In the file type dropdown, choose KML instead of KMZ.
. Save the file.

== Creating Multiple Markers

For a group of related markers, place them in a folder before saving.

. In the Places panel, right-click My Places or Temporary Places.
. Choose menu: Add[Folder].
. Name the folder.
. Add placemarks inside that folder.
. Check that each placemark has the correct name, position, and description.
. Right-click the folder.
. Choose menu: Save Place As[].
. Select KML as the output type.
. Save the file.

Saving a folder creates one KML file containing all placemarks in that folder.

== Coordinate Order

KML coordinates use this order:

[source,text]
----
longitude,latitude,elevation
----

This is different from the common latitude/longitude order used in many mapping tools.

For example:

[source,xml]
----
<coordinates>-71.0589,42.3601,0</coordinates>
----

means:

[cols="1,2",options="header"]
|===
| Value | Meaning

| `-71.0589` | Longitude
| `42.3601` | Latitude
| `0` | Elevation
|===

== Basic KML Marker File Example

A simple KML marker file looks like this:

[source,xml]
----
<?xml version="1.0" encoding="UTF-8"?>
<kml xmlns="http://www.opengis.net/kml/2.2">
  <Document>
    <name>Route Markers</name>

    <Placemark>
      <name>Station A</name>
      <description>Example station marker</description>
      <Point>
        <coordinates>-71.0589,42.3601,0</coordinates>
      </Point>
    </Placemark>

  </Document>
</kml>
----

== Multiple Marker Example

[source,xml]
----
<?xml version="1.0" encoding="UTF-8"?>
<kml xmlns="http://www.opengis.net/kml/2.2">
  <Document>
    <name>Route Reference Markers</name>

    <Placemark>
      <name>Station A</name>
      <description>Main station reference point</description>
      <Point>
        <coordinates>-71.0589,42.3601,0</coordinates>
      </Point>
    </Placemark>

    <Placemark>
      <name>Yard Entrance</name>
      <description>Approximate start of yard trackwork</description>
      <Point>
        <coordinates>-71.0610,42.3588,0</coordinates>
      </Point>
    </Placemark>

  </Document>
</kml>
----

== Good Practices

* Use clear marker names.
* Add descriptions when the marker purpose is not obvious.
* Keep related markers in folders.
* Save simple marker sets as `.kml` so they remain readable.
* Use `.kmz` only when bundled icons, overlays, or images are needed.
* Check coordinates carefully before using the KML as a route-building reference.

[WARNING]
====
KML uses `longitude,latitude,elevation`. If coordinates are entered in `latitude,longitude` order, the marker may appear in the wrong part of the world.
====

== Suggested Route-Building Uses

KML marker files can be useful for documenting:

* station locations
* mileposts
* yards and sidings
* bridge and tunnel locations
* road crossings
* signal reference points
* scenery landmarks
* survey notes
* route boundaries

For route-building documentation, a KML marker file provides a lightweight way to preserve geographic reference points outside the route editor.
